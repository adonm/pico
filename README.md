# Pico CSS

A modern CSS framework - a fork of [PicoCSS](https://picocss.com) rebuilt with `light-dark()`, `color-mix()`, CSS nesting, and cascade layers.

**[View Docs &rarr;](https://adonm.github.io/pico/)**

## Features

- Automatic light/dark mode via `light-dark()`
- Two-variable theming (`--pico-primary`, `--pico-secondary`)
- 28 utility icons that inherit text color
- No build step required
- ~78kb minified

## Quick Start

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/adonm/pico/css/pico.min.css">
```

## Development

```bash
mise install      # Install tools
mise run dev      # Start dev server
mise run check    # Lint, format, build
```
